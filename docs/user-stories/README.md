# User Stories

User stories describe product behavior. Local issues divide stories into small,
verifiable implementation slices.

## Required Story Sections

Every story contains:

- User Story
- Context
- Acceptance Criteria
- Out of Scope
- Risks
- Follow-up Issues
- Implementation Order

Filename format: `US-NNNN-short-title.md`.
